# Стартовый промпт для Codex

Скопируйте текст ниже в Codex на целевом Mac и приложите путь к переданному DMG или каталогу исходников.

---

Подготовь A-notes к локальной работе на этом Mac. Разрешаю прочитать и смонтировать переданный архив, установить приложение и Ollama в доступный каталог Applications, скачать одну локальную модель Llama, запустить Ollama на loopback, сохранить рабочий профиль A-notes и выполнить синтетический аудит. Если я передал исходники или попросил переупаковать проект, разрешаю пересобрать и запаковать новый DMG. Выполняй эти шаги самостоятельно.

1. Прочитай README и AGENTS.md. Проверь Apple Silicon, macOS 15+, память и место для приложения, архива, временных файлов и одной модели. Для полученного DMG проверь SHA-256 и `hdiutil verify`, смонтируй его read-only, проверь подпись app через `codesign --verify --deep --strict` и оцени Gatekeeper через `spctl`. Используй образ как источник для установки и проверки.
2. Если входом были исходники или запрошена переупаковка, запусти `swift test` и `PACKAGE_HANDOFF=1 ./scripts/package-app.sh`. Возьми уже имеющиеся веса и токенизатор из `Contents/Resources/OfflineASR` переданного приложения либо локального кэша WhisperKit. При необходимости передай их через `ASR_SOURCE` и `TOKENIZER_SOURCE`. Проверяй итоговый DMG. Сохраняй переданный архив и имеющиеся приложения при сборке.
3. Установи проверенную app в Applications, где у текущего пользователя есть права записи. Обновление делай после завершения активной записи и обработки. Сохрани существующую библиотеку и настройки других профилей. При блокировке Gatekeeper сообщи статус подписи и требуемое действие владельца. Не меняй политики защиты macOS.
4. Найди Ollama на `127.0.0.1:11434`, в PATH, `/Applications` или `~/Applications`. Если Ollama отсутствует, открой официальную страницу https://ollama.com/download/mac, скачай актуальный подписанный образ, проверь его и скопируй Ollama.app в доступный Applications. Используй вложенный CLI `Ollama.app/Contents/Resources/ollama`, чтобы установка ссылки в PATH не требовала административного пароля. Запусти `Project/scripts/setup-local.sh "/фактический/путь/A-notes.app" llama3.2:3b`. Скрипт запустит локальный сервер при необходимости, скачает модель при отсутствии, проверит встроенный Whisper и сохранит профиль после успешного inference. Используй `llama3.2:1b`, если установленная модель подходит по ресурсам лучше или для 3B не хватает места или памяти. Используй только локальные веса. При штатном запуске Ollama после перезагрузки перепроверь его API.
5. Выполни `Project/scripts/audit-handoff.sh "/фактический/путь/к-архиву.dmg" MODEL_ID` с тем же ID. Требуется реальный прогон из DMG, включая загрузку Whisper без сети, распознавание обоих синтетических треков, создание итога через Llama и открытие сохранённой библиотеки вторым процессом. Если что-то упало, диагностируй, исправь и повтори. Существующие встречи для аудита не используй.
6. Запусти приложение и проверь окно. Для проверки захвата попроси владельца только о системном разрешении, если оно потребуется. Когда разрешение уже выдано, проведи тест захвата на новой синтетической записи. Потребность в пароле, разрешении macOS или подписи Developer ID сообщи одним конкретным действием, выполнив доступные независимые проверки.
7. Верни путь к приложению, архиву и SHA-256, фактическую модель и адрес, результаты проверки подписи, офлайн Whisper, очереди, итога, повторного открытия и реального захвата. Сохрани журнал аудита рядом с архивом.
