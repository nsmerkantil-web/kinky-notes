# Обработка записей и восстановление — 5 ноября 2026

Ручное создание итога и обработка нового звонка используют одну последовательную очередь. До начала запроса сохраняются `pending`, этап и время постановки. Повторное нажатие для того же задания блокируется. В карточке отсутствующего итога при готовом транскрипте показывается «Запустить итог заново», во время обработки — индикатор и текущий этап; обновление уже готового итога также видно в нижнем статусе.

При запуске приложение проверяет все встречи: восстанавливает сохранённые задания и находит аудио/транскрипты без итога. Готовый транскрипт используется повторно. Ошибки распознавания и записи без обнаруженной речи не запускаются в бесконечном цикле; для них остаётся ручной повтор. Ошибка итога остаётся доступной для повтора; при следующем запуске приложения отсутствующий итог снова попадает в очередь.

Фоновая обработка использует `userInitiatedAllowingIdleSystemSleep`: App Nap не должен тормозить активную работу, но системный сон разрешён. Локальный ASR и Ollama во время системного сна продолжать вычисления не могут. На `NSWorkspace.willSleepNotification` задания сохраняются, активный запрос отменяется, запись при необходимости финализируется. На `didWakeNotification` очередь возобновляется после завершения отменённого worker. Системный сон не заменяется искусственным удержанием Mac во включённом состоянии.

ASR сохраняет атомарную контрольную точку после каждого 30-секундного фрагмента, с отдельными позициями двух аудиодорожек. После прерывания уже обработанные фрагменты повторно не распознаются. Смена ASR-модели или явный запрос повторного распознавания начинает новый проход. Аудио не удаляется. Итог строится из ограниченных частей транскрипта с последующим объединением; после прерывания создание итога запускается с начала.

Ollama получает JSON Schema, ограничения длины ответа и `think: false`, чтобы бюджет ответа использовался на итог. При `token repeat limit` или некорректном JSON выполняется один повтор с другими параметрами генерации. После повторной ошибки задача завершается с доступной кнопкой повтора; бесконечных автоматических запросов нет.
