# A-notes. Карта функций перед редизайном

9 ноября 2026 · нативное приложение macOS · инвентаризация по исходникам и документации проекта. Существующие скриншоты использованы как визуальный ориентир. Сценарий реального звонка в рамках этой работы не запускался.

## Что есть в приложении

| Зона | Текущее поведение |
| --- | --- |
| Библиотека | «Все заметки», «Входящие», пользовательские папки. Записи сгруппированы по дате. Поиск по названию, заметкам, транскрипту и итогу в текущей области. Ручная заметка без аудио, показ/скрытие боковой панели. |
| Папки и записи | Создание, переименование, удаление папки с возвратом её записей во «Входящие». Перемещение записи, контекстное меню и подтверждение удаления. При удалении встречи Markdown архивируется, аудио перемещается в Корзину. Во время записи и обработки удаление ограничено. |
| Обнаружение звонка | Активный микрофон Teams или Chrome служит сигналом звонка. В настройках три режима: вручную, предложить запись через уведомление, начать автоматически. Сигнал не даёт названия созвона или календарного контекста. |
| Захват | Кнопки запуска и остановки, отдельные дорожки микрофона и системного звука, разрешения macOS, автоматическая остановка после устойчивого исчезновения сигнала звонка, уведомление по завершении. При успешном старте создаётся встреча и подаётся сигнал открыть её. Есть общая строка захвата и текстовый статус конкретной встречи. |
| Обработка | После сохранения аудио — очередь, локальное распознавание WhisperKit для RU/EN, генерация итога и названия через выбранную модель. Ручные названия защищены от автозамены. Очередь и контрольные точки распознавания сохраняются, прерванная обработка возобновляется. Готовый транскрипт можно использовать для повтора итога. |
| Открытая встреча | Редактируемое название, дата, папка, вкладки «Итог», «Транскрипт» и «Заметки». Итог можно редактировать, заметки автосохраняются. В транскрипте есть таймкоды и стороны разговора. Имена могут появляться, если модель нашла их в тексте. |
| Ошибки и повтор | Есть этапы очереди, распознавания и итога, сообщения об ошибках записи, отсутствующей речи и сбое модели. Доступны повторное распознавание и отдельный повтор или обновление итога. |
| Файлы и экспорт | Обзор и индексы папок в Obsidian, Markdown встречи, обновление текстов из vault, сохранение истории и конфликтующих копий. В приложении можно показать Markdown или аудиофайлы в Finder, экспортировать .txt или открыть текст в редакторе macOS. Пользовательские теги живут в Obsidian. |
| Настройки | Режим захвата, модель Whisper, профиль Ollama/LM Studio, адрес и модель сервера, проверка связи, обновление списка моделей, токен в Keychain, переход к уведомлениям macOS и настройке Obsidian. |

## Что меняется в концептах

1. **При открытии окна во время автозаписи.** Показать закреплённую область «Сейчас» поверх любой папки или поиска. Два разных сигнала: «Звонок активен» и «Идёт запись · 08:42». Отметить режим «Автозапись», дать «Открыть запись» и отдельное «Остановить». При возврате в окно оставить текущий контекст и сохранить один клик до активной встречи. Если приложение запущено заново, факт захвата появляется только после успешного запуска аудиопотока.
2. **При просмотре встречи.** Поместить «← Все заметки» или имя исходной папки в шапку документа. По возврату восстановить папку, запрос и позицию списка. Сделать папку компактной кнопкой рядом с датой. В меню выбора — только список папок с отметкой текущей, а удаление и прочие операции — в «⋯». Во время записи удобная стартовая вкладка — «Заметки». По окончании показывать прогресс итога рядом с вкладками.
3. **При чтении списка.** Каждая строка имеет единый фон hover с внутренними отступами и зарезервированным местом под «⋯». Выбор и клавиатурный фокус отличаются от hover, ширина строки и позиция текста не прыгают. Папка получает короткую цветную метку с именем. Это первый уровень color coding на существующих данных. Произвольные теги внутри приложения — отдельное расширение, которому понадобится хранение и договорённость об обмене с Obsidian.
4. **При обработке.** Компактные статусы с текстом и иконкой: «В очереди», «Распознавание», «Создаём итог», «Готово», «Нужен повтор», «Заметка без аудио». При ошибке итога отдельно показать, что транскрипт готов. Красный сигнал с таймером появляется после подтверждения захвата. При остановке таймер уступает тексту «Сохраняем аудио», затем показывается этап очереди.
5. **Визуальные правила.** SF Pro или сопоставимый sans-serif во всём интерфейсе, включая крупные заголовки и таймер. Шкала отступов кратна 8, текст списка 14–16 pt, заголовки 28–36 pt. Цвет статуса дублируется текстом и формой. Явный focus ring и действия доступны с клавиатуры. Изображения передают отдельные состояния интерфейса. Hover, восстановление навигации и поведение при возврате в окно описаны как сценарии для последующей проверки.

## Состояния верхней панели

| Событие | Что видит пользователь | Действие |
| --- | --- | --- |
| Детектор заметил звонок, захват ещё не запущен | «Звонок активен» и «Запись не начата». При автозапуске на короткое время — «Запускаем запись». | «Записать», если режим допускает ручной запуск и запуск ещё не идёт. |
| Захват идёт | Красная точка, «Идёт запись», время с начала захвата. «Автозапись» показывается, только если запуск был автоматическим. | «Открыть запись» и «Остановить». |
| Ручная запись без сигнала звонка | «Идёт запись» и таймер. | Те же действия с записью. |
| Захват завершён | Короткое «Сохраняем аудио», затем статус в строке встречи. При прерывании показать, удалось ли сохранить аудио. | «Открыть запись» или контекстное действие для ошибки. |
| Архив открыт во время записи | Закреплённый статус остаётся видимым при смене папки и прокрутке. На узком окне подписи укладываются в две строки. | Один клик до встречи. |

Отдельный интерфейс для состояния детектора и метки происхождения запуска потребует вывести эти данные из логики захвата в модель интерфейса. Цветные метки папок можно показать раньше произвольных тегов.

## Три направления

- **Хвойная библиотека.** Архив — главный экран. Спокойные тёмные поверхности, зелёный акцент, заметная закреплённая строка «Сейчас» над встречами. Для работы с большим количеством прошлых записей.
- **Лист встречи.** Документ — главный экран. Тёплая светлая поверхность, тёмно-зелёные действия, компактная навигация, понятное соседство названия, папки и возврата. В образце открыт итог прошлой встречи, активная запись доступна сверху.
- **Студия записи.** Активная встреча — главный экран. Глубокий зелёно-чёрный фон, более энергичный лаймовый акцент, отдельный блок захвата и сразу открытые заметки. Возврат в архив остаётся рядом с названием.

У всех направлений одна модель данных. В макетах используются демонстрационные встречи. Живое распознавание, автоматические названия текущего созвона и встроенный аудиоплеер не входят в этот дизайн.
