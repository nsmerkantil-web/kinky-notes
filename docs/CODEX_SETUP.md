# Настрой A-notes без лишних вопросов

Скопируйте текст ниже в свой Codex, подключённый к этому Mac. Инструкция предназначена для установки готового приложения: исходники, Xcode, Node.js, Python и Homebrew для A-notes не нужны.

---

Настрой на моём Mac A-notes для локальной записи встреч, расшифровки и создания итогов через Ollama или LM Studio. Не задавай вопросов о рутинных шагах и выборе технологий: самостоятельно исследуй компьютер, выбери рабочий вариант и доведи настройку до проверенного результата.

Разрешаю установить переданную мне A-notes.app в Applications, найти или установить Ollama либо LM Studio с официального сайта, запустить выбранный сервер на loopback, при необходимости скачать одну подходящую локальную текстовую модель и настроить A-notes. Сначала используй уже установленный и работающий вариант. Если работают оба, сохрани уже настроенный в A-notes; если настройки нет — выбери Ollama. Если ничего не установлено — выбери Ollama как основной путь. Не подключай облачные API и модели. В первой версии поддерживаются только Ollama и LM Studio.

Ограничивай вопросы случаями, которые действительно требуют моего действия: ввод административного пароля, выдача разрешения macOS, принятие условий gated-модели или отсутствие необходимого файла. В таком случае дай одно конкретное действие и продолжи после него. Не проси подтверждать каждый шаг. Не считай истечение времени разрешением на действие.

Выполни следующее:

1. Найди переданный установочный DMG или A-notes.app, прочитай GETTING_STARTED.md и SIGNING_STATUS.txt, если он есть. Проверь подпись и архитектуру. Поддерживается Apple Silicon и macOS 15+. Существующие записи и настройки сохрани. Не заменяй и не перезапускай приложение во время записи или обработки. Если требуется остановка активной записи, дождись её естественного завершения либо сообщи, какое действие нужно от меня.
2. Проверь свободное место и RAM. Не скачивай большой 20B/27B-пресет по умолчанию. Сначала используй уже имеющуюся локальную instruction/chat-модель, подходящую для русского и английского. При отсутствии выбери актуальную небольшую multilingual instruction-модель по официальной карточке, совместимую с выбранным движком и памятью этого Mac; учитывай веса, контекст и резерв для системы и Whisper. Проверь лицензию и размер до скачивания. Скачай только одну модель. Не удаляй мои существующие модели ради места. При нехватке диска/памяти сообщи конкретный блокер.
3. Установи app, если её ещё нет. Не требуй установки Whisper: WhisperKit, модель large-v3_turbo и tokenizer входят в полный дистрибутив. Не отключай Gatekeeper, SIP или проверку сертификатов и не выполняй массовое удаление quarantine. Если локальная бета блокируется политиками macOS, сообщи ограничение подписи и конкретное необходимое действие; не утверждай, что она нотарифицирована Apple.
4. Проверь локальные серверы с короткими таймаутами: Ollama `http://127.0.0.1:11434/api/tags`, LM Studio `http://127.0.0.1:1234/v1/models`. Не сканируй LAN. Если адрес уже задан пользователем — сначала проверь его. Не запускай второй сервер на занятом порту и не меняй глобальную конфигурацию работающего сервера.
5. Для Ollama: найди установленное приложение или executable, запусти сервер, проверь каталог моделей и нужную модель. При необходимости используй официальный механизм pull. Убедись, что модель локальная: адрес localhost сам по себе не доказывает отсутствие облака.
6. Для LM Studio: запусти приложение и API Server в Developer tab либо используй установленный `lms`. При первом использовании CLI проверь `lms --help`, не выдумывай команды загрузки. Выбери/загрузи модель и проверь `/v1/models`. Не отключай уже включённую авторизацию. Если нужен токен, используй только предоставленный мной или созданный для этой интеграции; сохраняй через SecureField A-notes или stdin-команду ниже, не через аргументы командной строки и не в текстовые файлы. Не выводи токены в чат или журналы.
7. Настрой A-notes с помощью встроенной команды ниже или через Настройки. Укажи точный model ID из каталога, соответствующий провайдер и URL. Настройки сохраняются отдельно для Ollama и LM Studio. Начни с контекста 16K; для LM Studio выставь соответствующий контекст в сервере. Если память не позволяет, выбери меньшую модель; не обещай работу длинных итогов только по короткому ответу OK.
8. Проверь фактический inference на синтетическом тексте, затем встроенные ASR assets. Если тест не прошёл, исправь причину и повтори. Успешные GET /models, сборка или наличие процесса не доказывают готовность.
9. Проверь разрешения микрофона и системного звука. Пользователь должен выдать их сам через штатный диалог macOS. Не редактируй TCC базу. После выдачи разрешений и при отсутствии активной записи разрешаю штатный перезапуск A-notes, если он нужен для их применения.
10. Для проверки полного цикла используй только новую синтетическую тестовую запись с пометкой TEST. Не читай мои существующие встречи и не отправляй их для диагностики. Убедись, что сохранены аудио, непустой транскрипт и итог, затем что они открываются после перезапуска. Если разрешения или окружение не позволяют такой тест, явно укажи непроверенный этап.
11. Заверши коротким отчётом: путь установленной app, провайдер, адрес, модель, результаты каталога/inference/ASR/полного цикла, оставшиеся ограничения. Не пиши «всё готово», если какой-то обязательный этап не прошёл.

## Встроенные команды для настройки и проверки

Ниже предполагается установка в `/Applications/A-notes.app`. Если app в другом месте, используй её фактический абсолютный путь. Команды выполняются без GUI и не читают записи встреч.

Ollama — замени `EXACT_MODEL_ID` на ID из `/api/tags`:

```sh
"/Applications/A-notes.app/Contents/MacOS/A-notes" --configure-local-model \
  --provider ollama --server http://127.0.0.1:11434 --model EXACT_MODEL_ID
```

LM Studio — замени `EXACT_MODEL_ID` на ID из `/v1/models`:

```sh
"/Applications/A-notes.app/Contents/MacOS/A-notes" --configure-local-model \
  --provider lm-studio --server http://127.0.0.1:1234/v1 --model EXACT_MODEL_ID
```

Если сервер требует API token, к configure-команде можно добавить `--token-stdin` и передать токен одной строкой через защищённый stdin. Не вставляй значение токена в текст команды. Токен сохраняется в macOS Keychain и привязывается к провайдеру/адресу. После изменения адреса нужен токен для нового адреса.

```sh
"/Applications/A-notes.app/Contents/MacOS/A-notes" --check-local-model
"/Applications/A-notes.app/Contents/MacOS/A-notes" --check-bundled-asr
```

Первая команда проверяет выбранную модель в каталоге и реальный короткий ответ. Вторая загружает встроенные веса и tokenizer; она не доказывает качество распознавания. Дополнительная проверка распознавания использует подготовленный синтетический EN-аудиофайл:

```sh
"/Applications/A-notes.app/Contents/MacOS/A-notes" --transcribe-check /absolute/path/to/synthetic-test.wav
```

Настройки применяются новым заданием в этой версии A-notes. Уже выполняющееся задание сохраняет прежнее подключение. В старой версии может потребоваться штатный перезапуск после завершения активной записи/обработки. В GUI открой Настройки повторно, чтобы увидеть настройки, изменённые внешней командой.

Подключение LLM влияет только на текстовые задачи. Аудио и транскрипт остаются локально; при недоступном сервере итог можно создать повторно после восстановления подключения.
