# A-notes 1.0 — первая локальная бета

Mac с Apple Silicon, macOS 15 или новее. Подключения для итогов: только Ollama и LM Studio.

## Установка

Перенесите A-notes.app в Applications. В полном пакете уже есть WhisperKit, Whisper large-v3_turbo и tokenizer — примерно 3 ГБ. Python, Node.js, Xcode и отдельная установка Whisper не нужны. Первый запуск распознавания может занять время для подготовки Core ML.

Если рядом есть SIGNING_STATUS.txt, прочитайте его: локальная бета не прошла нотарификацию Apple и может блокироваться Gatekeeper другого Mac. Для обычной внешней поставки требуется сборка с Developer ID и нотарификацией. Не отключайте защиту macOS.

## Подключите модель для итогов

1. Установите [Ollama](https://ollama.com/download/mac) или [LM Studio](https://lmstudio.ai/download), скачайте подходящую текстовую модель с поддержкой нужных языков.
2. Запустите выбранное приложение. В LM Studio включите API Server в Developer tab; начните с контекста 16K, если хватает памяти.
3. В A-notes откройте Настройки, выберите Ollama или LM Studio. Адреса по умолчанию уже заданы; при нестандартном порте исправьте адрес.
4. Нажмите «Обновить список моделей», выберите модель через «Выбрать» либо введите точный ID и нажмите «Проверить связь».
5. Если на сервере включена авторизация, введите токен и нажмите «Сохранить токен». Он хранится в Связке ключей, отдельно для каждого адреса. Пустое поле после сохранения нормально.

Наличие модели в списке не гарантирует, что ей хватит памяти для длинного звонка. Избегайте слишком больших моделей. Ollama также поддерживает облачные модели: для полностью локальной работы выбирайте именно локальную модель.

Можно поручить настройку своему Codex: передайте ему соседний **CODEX_SETUP.md**. Инструкция также доступна в Настройках A-notes.

## Запись

Выдайте разрешения macOS на микрофон и системный звук. Если macOS просит перезапустить приложение, дождитесь завершения текущей записи. Нажмите кнопку записи, затем остановите её. Приложение сохраняет аудио, создаёт транскрипт и запрашивает итог у выбранной модели. Обработка идёт по очереди с видимым этапом.

Если сервер не отвечает, транскрипт сохраняется. Исправьте подключение и запустите создание итога повторно из меню записи. Изменение настроек не перенаправляет уже поставленное в очередь задание; новый явный запуск итога использует новые настройки.

Тексты по умолчанию находятся в отдельном хранилище `~/Documents/A-notes`; служебная библиотека и аудио — в `~/Library/Application Support/AntonNotes`. Obsidian для работы A-notes устанавливать не обязательно. Не перемещайте служебные файлы вручную во время обработки.

## Статус проверки

Это первая бета, а не обещание совместимости с любой моделью. Текущие результаты и ограничения находятся в отчёте `docs/validation/2026-11-05-packaging.md` в исходном проекте. Проверка короткого ответа не заменяет проверку реальной записи, разрешений и длинных итогов на вашем Mac.
