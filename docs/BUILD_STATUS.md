# Состояние реализации

Актуальная упаковка от 5 ноября 2026: [локальная бета с Ollama/LM Studio, результаты и ограничения](validation/2026-11-05-packaging.md). Полный пакет — `dist/release/`; инструкция пользователя — [GETTING_STARTED.md](GETTING_STARTED.md).

## Первоначальный снимок — 2026-10-27

Ранний прототип, не готовый MVP.

Сборка: `scripts/build-app.sh`. Результат: `dist/A-notes.app`.
Данные: `~/Library/Application Support/AntonNotes/`.

Реализованы: нативный редактор встреч и папок-меток, поиск, атомарное сохранение JSON, ручная запись mic/system в отдельные CAF через ScreenCaptureKit, сигнал активности Teams/Chrome с ручным/предлагающим/автоматическим режимом, локальный WhisperKit, локальный Ollama (gemma3:27b по умолчанию). Whisper-модель загружается при первом распознавании; сеть нужна для начальной загрузки весов.

Проверены компиляция и упаковка с подписью ad hoc. Реальные звонки не записывались; точность детектора, качество аудио/ASR и производительность пока не проверены.

Существенные ограничения: нет автоматического завершения, паузы, групповой диаризации, очереди обработки, chunk crash recovery, корзины, versioned правок и надёжной обработки длинного контекста. Записывается общий системный звук, не изолированный Teams/Chrome. Системные аудиодорожки пока не выровнены по timestamps. Ошибки записи выводятся в системный журнал; интерфейс ещё не обеспечивает достаточную диагностику. Настройки режима не сохраняются. Транскрипция может заменить ручные изменения — не редактировать её во время обработки. В текущем состоянии не использовать для единственной копии важных разговоров.

Следующий этап: lifecycle capture с ошибками и timestamps, длительные записи небольшими chunks, стабильное хранилище и очередь, автоматическая post-call обработка, тестовый корпус и реальный smoke test с разрешениями. Сначала устранить эти ограничения, затем считать beta.

Пользователь подтвердил: inference локальный; допускается post-call обработка, ориентир до 90 минут обработки часовой записи. Показатели пока не измерялись. Codex как отдельный облачный провайдер не включён.

## Обновление интерфейса

По предоставленному скриншоту Granola: тёмные поверхности, боковая панель 248 px, один список папок без рабочих пространств, список заметок с группировкой по датам, отдельный редактор. Календарь, приглашения и тарифы отсутствуют. Акцент — жёлто-кораллово-фиолетово-синий градиент. Настройки модели и режима записи перенесены в sheet. Сборка и упаковка проверены; визуальная проверка запущенного нового окна ещё не выполнена.

## 2026-10-28 — уточнение визуального соответствия

Предыдущая интерпретация отменена: экран повторяет предоставленный Granola Home с исключением календаря и разделения пользователей. Сохранены Home/Shared with me/Chat, верхние Invite/New note, нижние иконки, Basic Plan/Upgrade, workspace и Ask anything/List recent todos. Общий раздел Folders содержит реальные папки. Неподключённые действия показывают явные пояснения. Градиент используется в значке и AI-акцентах.

Сборка и codesign проходят. Снимок реального окна проверен; исправлены ширина sidebar, titlebar inset и перенос Upgrade/workspace. Отдельный `--design-preview` использует Application Support/AntonNotes-DesignPreview; рабочий архив не заполняется примерами. Проверена фильтрация Design Daily через AX и возврат Home. Размер окна ограничен высотой текущего дисплея, поэтому точное попиксельное совпадение с исходным viewport не подтверждено.

## 2026-10-28 — исправления разрешений и диагностика звонков

Подтверждён TCC code-requirement mismatch после ad-hoc пересборок. Упаковка переведена на постоянный локальный сертификат с привязкой к сертификату и bundle ID; проверена совместимость подписи изменённой копии. Старое разрешение нужно один раз обновить. Это локальная подпись, не Developer ID.

Добавлены нативные macOS-уведомления Call detected / Take notes, видимый статус, блокировка повторного старта, сохранение режима и модели, закрытие файлов перед ASR, автоматическое распознавание после ручной остановки и пропуск полностью тихих дорожек. Новая заметка появляется после успешного старта захвата. Логи статусов: Application Support/AntonNotes/diagnostics.log. Детали и ограничения: validation/2026-10-28-call-audit.md.

Runtime smoke test 00:44: stale ScreenCapture entry replaced with current signed bundle; `screenPermission=true`. macOS notifications enabled and usernoted confirms banner + Notification Center delivery. Eleven-second capture of microphone and system test tone succeeded with nonzero audio on both tracks. Stop automatically started ASR; initial model download remains in progress, so end-to-end inference is not yet verified.


## 2026-11-03 — аудит и исправления интерфейса

Приведены к общему стилю кнопки, вкладки и состояния; выделение папки охватывает меню. Настройки переведены в нативный popover с крестиком, «Готово» и Escape. Запись доступна из toolbar; повторная обработка находится в меню записи. Сохранение заметок автоматическое; добавлены экспорт всей встречи в UTF-8 .txt и открытие текстового снимка. Заголовки переносятся; поиск включает итог и очищается при закрытии.

20 тестов, сборка и локальная подпись прошли. Проверены AX-действия в изолированном preview, включая закрытие настроек, вкладки и экспортное меню; запись заметок проверена в library.json без Save. Физические hover/press, клик вне popover, Escape и новый реальный звонок требуют ручной проверки. Подробности: [аудит и проверка](validation/2026-11-03-ui/AUDIT.md).
