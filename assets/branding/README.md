# A-notes identity

`a-notes-logo.png` is the retained master image produced with the built-in imagegen tool. `AppIcon.icns` packages all standard macOS icon sizes, generated by `scripts/build-icon.sh` using sips and iconutil. `scripts/build-app.sh` rebuilds the icon and embeds it in the signed application.

The bundle ID and signing identity remain unchanged for continuity of stored permissions; the existing AntonNotes application-support directory and defaults remain the data source. The shipped application bundle, executable, window and display name are A-notes.

Generation prompt:

> Use case: logo-brand. Create one polished macOS app icon for A-notes, a private audio meeting notes application. Square 1024x1024 icon artwork: a dark charcoal rounded-square tile with generous transparent outer margins appropriate to macOS app icons, a warm ivory geometric capital A at the center; its crossbar is a small understated warm amber audio waveform, joining the legs into one coherent distinctive monogram. Minimal confident functional design, exact geometric edges, subtle native dimensionality on tile only, high readability at 32px. No wordmark, no other letters, no microphone pictogram, no mockup, no surrounding objects, no watermark. Actual transparent background outside the rounded-square tile.
