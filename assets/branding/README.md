# Kinky Notes app icon

`kinky-notes-app-icon.png` is the square master for the macOS app icon. The curved K uses the sage green from the dark appearance accent in `Sources/AntonNotes/InterfaceStyle.swift` over a charcoal gradient.

`scripts/build-icon.sh` generates `AppIcon.icns` from the master. The build script embeds it in the signed app. `favicon.png` is the 32 × 32 browser asset from the same master.
