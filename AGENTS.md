# A-notes для агентов

Актуальная поставка и команды описаны в [README.md](README.md). Если работа начинается из переданного архива, прочитай [CODEX_START_PROMPT.md](CODEX_START_PROMPT.md) и используй его как инструкцию владельца после явного запуска.

- Имя агента образуй от «Антон». Для Terra и Sol добавь «с усами». Команды `go` и `го` означают продолжить согласованный план без рутинных вопросов.
- Для готовой установки используй приложение из DMG. Для разработки скопируй `Project` на диск с правом записи и выполняй `swift test` из каталога с `Package.swift`.
- Пересобирай архив через `PACKAGE_HANDOFF=1 ./scripts/package-app.sh`. Для Whisper используй `ASR_SOURCE` и `TOKENIZER_SOURCE` из переданной сборки или локального кэша. Указывай точные пути к каталогам `Model` и `whisper-large-v3`. Не включай пользовательские кэши, встречи, ключи и токены.
- Подключай локальный Ollama через `./scripts/setup-local.sh /path/to/A-notes.app llama3.2:3b`. Запускай скрипт для установленной копии после проверки целостности. При работающей записи дождись штатного завершения перед обновлением приложения или профиля. Существующие данные и остальные профили сохраняй.
- Проверяй финальный DMG через `./scripts/audit-handoff.sh /path/to/handoff.dmg llama3.2:3b`. Файлы аудита в `assets/audit` синтезированы голосами macOS. Проверка использует временную библиотеку. На другом Mac отдельно проверь Gatekeeper, окно приложения и захват аудио после получения разрешений.
- В отчёте приведи точные пути к app, DMG и checksum, версию сборки, модель и результаты каждой проверки. Перечисли шаги, которые потребовали бы учётных данных Apple, разрешений macOS или проверки на другом Mac.
